# 맵 스폰 슬롯 표

## 1. 다음 단위 작업

이 표에는 확정된 다음 제작 작업이 없다. 맵 스폰이나 지역 데이터 배정을 수정할 때 해당 슬롯 번호와 생성 의도를 대조한다.

## 2. 전체 작업 TODO 및 진행상황

세 맵의 슬롯 생성 의도를 기록한 참고 표다. 실제 지역 데이터의 배정·검증 진행률은 이 문서에 기록되지 않았다.

- [ ] 배정을 변경할 때 해당 `SpawnSlot_NNN`과 지역 데이터를 함께 확인한다.
