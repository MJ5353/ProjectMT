# 26.11.18 - 데이터 도구·전투 구현과 아트 제작

## 주요 작업

- 데이터 편집기·몬스터/스폰 자동 배정 구현.
- 부위 파괴·공격/스킬·애니메이션 연결과 스폰 버그 수정.
- 지역·시장·HUD 아이콘 제작, 액터 실행 구조 공통화.

## 데이터 편집기·자동 배정

- 직접 타입별 표·연관 Def·모델 차이·빌드를 요구하고 필드 나열식 초안은 거절. AI가 UI Toolkit의 표 직접 편집+상세 영역으로 재구현, 기존 변경은 보존.
- 모델 등록·Def 삭제·버섯 모델별 제안·빌드를 연결. 임시 에셋으로 중복·값/GUID 보존·저장·Undo·삭제 후 재제안 확인, 실제 Def 삭제는 취소.
- 직접 맵-버섯-몬스터 연계와 순서 기반 공식을 요청. 밸런스는 MonsterBalance에서 조정하고 판정·히트스톱은 자동 배정 제외. 공유 HitDef 보호를 위해 넉백 자동 배정도 제거.
- 스폰 배치는 잡몹·엘리트·보스 규칙으로 자동화하고 기존 리스폰 유지. 미리보기만 확인, 적용은 직접 실행. 지역 버섯·밸런스 수치는 가안.

## 피격·부위 파괴·보스 조립

- 직접 피격 반응 통합을 지시하고 수치는 손으로 이전. AI가 HitFeature·공유 HitDef와 뼈 기반 몸 판정을 구현.
- 부위 종류·소켓을 정리하고 원본 뼈 참조를 프리팹으로 이동. 계획에만 완료로 적힌 부위 기능을 실제 구현한 뒤, 직접 보스 나무 기준·보스만 파괴로 범위 결정.
- 보스 3종의 부위·깨진 모델·드랍·공격 데이터를 연결. 부위당 파괴 칸 하나라 일부는 장식. 곰의 구름버섯 데이터는 수정, 당시 누락 판정·재굽기는 과제로 남김. 임시값이며 컴파일 또는 로드만 확인.
- 이후 직접 부위 단위 파괴·랜덤 버섯을 선택. PartEntry·UnitProperty로 개편하고 PartFeature를 유닛당 하나로 통합. 모델은 미리 생성해 재배치하고 잡몹 소켓 유실은 None 부위로 보존. 후반 개편은 컴파일·실행 안 함.
- 번쩍이 오류는 깨지지 않는 부위를 몸 피격으로 처리해 수정. 큰 공격의 부위 우선 판정은 남겼고, 당시 신선도는 획득 뒤 버려져 저장·표시되지 않았음.
- 통 메시 부위 번쩍은 포기하고 기존 피격 좌표·조각으로 도트 타격 마크 제작·강조. 플레이어 피격에도 표시되며 수치는 임시, 컴파일만 확인·플레이 미확인.

## 공격·스킬·애니메이션

- 직접 공격 구간·공용/개별 쿨 분리와 기본 공격의 SkillDef화를 결정. AI는 실행·데이터 구조를 정리했고, 애니 길이 조회에 맞춰 클립=상태 이름으로 통일.
- 직접 공격 6종을 지정하고 PC에 Blender가 없어 클라우드 출력 선택. AI가 플레이어 클립·보스 Hitbox 방향을 수정해 FBX 출력·미리보기 확인. 다른 FBX·팔레트는 보존, Unity 임포트·플레이 미확인.
- 새 클립이 없는 FBX 연결은 원복했다가 새 파일로 재연결. 승인 후 좌→우→막타 콤보·달리다 베기·위로 치기 구현, 판정 전 연타 무시·콤보 초기화 적용. 임시값, 컴파일·로드만 확인.
- 내려치기는 보류하고 길게 누르기 회오리 선택. 입력 지연을 피하려 즉시 콤보 후 회오리 연결, 좌우 전환은 블렌딩 추가. 두 바퀴째 미타격은 재타격 간격으로 수정. 컴파일만 확인.
- 보스 공격 불가는 캡슐 표면 기준 거리와 실제 클립으로 수정. 회전 속도·피격 색·몸 판정도 데이터화했으나 수치와 플레이 확인은 남음.

## 스폰·맵 버그 수정

- 직접 슬롯별 MonsterDef 직접 참조를 선택하고 런타임 Find·ID 간접 참조는 보류. 선택 맵은 씬 고정 대신 MapDef.Prefab에서 생성하도록 변경.
- 지면 보정만으로 해결되지 않던 낙하는 슬롯의 X 90도 회전이 원인. 스폰 yaw 제한 후 직접 지시해 FBX 가져오기 단계에서도 수정. 기존 가져오기 경고는 별개로 남음.
- 올라타기는 자동 계단 오르기로 확인해 접촉 시 stepOffset 0 적용·바닥 스냅 제거. 보스·곰·호랑이는 수동 Move로 해소 확인.
- 직접 레이어·맵 래핑·버퍼 없는 거리 비교를 선택. 지형으로 물리 쿼리 버퍼가 차는 문제를 피하고 사각형 검색은 이득 없어 보류. 구조 변경은 컴파일·플레이 미확인.

## 아이콘 제작

- **지역:** 직접 컨셉·스케치·수정 방향을 제시. AI가 평원/보스 나무·얼음·공룡/화산 3종을 스티커·디오라마로 제작. 캐릭터·소품·지역색 테두리를 보완하고 그림 64px+여백의 72px 캔버스로 정리. 초기 외형은 이름으로 추정, 임포트·MapDef 연결 안 함.
- **시장·HUD:** 직접 항목·크기·용도 지정. 버섯 5종·공통 썩음 덮개·변종 별, 조이스틱·공격·대시·밤 시계·종료 아이콘 제작. 모델 팔레트와 공용 덮개, 코드 색 적용·Radial360 방식 선택. 밤 시계·종료 아이콘은 연결·임포트 안 함.
- 생성 스크립트는 다른 결과물 덮어쓰기를 피하도록 분리. 자물쇠 등 추가 5종은 직접 판단 대기.

## 액터 실행 구조 공통화

- 직접 상속+Feature를 선택하고 ‘컨트롤러는 판단, Feature는 실행’으로 경계 설정. AI가 공격 선택·대시를 분리하고 공격 실행·Next 기반 콤보를 플레이어/몬스터 공용화.
- 유닛 Tick은 ActorService로 모으고 Despawn은 순회 후 처리. 씬 직접 배치는 미지원, 스폰은 Tick 밖에서만 처리하는 범위로 결정. 컴파일 안 함.

## 보조 도구·문서 정리

- **명명·이전:** 직접 3자리 번호·Mon/Mush/Map·DexNo 등을 확정. GUID·직렬화 값을 보존해 변경 후 일회성 이전 코드는 제거. 세이브는 직접 초기화를 선택했으며 버전 3 미만은 초기화 필요.
- **공용 도구·UI:** 사전/Inspector 추가, 샘플·메뉴·경로 정리. 사전의 미완성·중복 행 보존과 Undo·재로드 확인. 결과 UI는 템플릿을 그리드 밖으로 옮기도록 셋업 수정, 재생성은 직접 수행할 몫.
- **문서·환경:** 문서 형식·참고 링크·로그 경로 통일. 직접 graphify 삭제와 긴 스레드 정리·큰 파일 부분 읽기를 선택, AI가 연결·생성물·CLI 제거·실행 배치파일 작성. 토큰 원인 분석은 수치 근거 없는 추정.

# 26.11.19 - 공통 행동·이펙트 구조 정리와 제출 준비

## 주요 작업

- 공통 행동·AI·판정·부위 책임과 UnitController 구조 정리.
- 공격·부위 파괴·사망·줍기 이펙트 제작·서비스 통합.
- 제출 가치·마감 범위 평가, 라이선스·AI 협업 로그 정리.

## 액터 구조·책임 분리

- 직접 상태가 Feature를 감싸는 구조를 지적하고 AI도 Feature로, 컨트롤러는 허브로 선택. AI가 ActionFeature·공통 행동 5종·AIFeature·팀 기준 적 탐색 구현.
- 판단/행동 분리, 행동별 끊기 규칙·공격 안의 예고·종료 알림 순서로 중복과 콤보 충돌 개선. 병행 작업 중인 공격·피격 파일은 보존.
- 직접 판정/파괴 분리 채택. 몸 판정은 HitBoxFeature, 부위 번호·드롭·피격 연결은 PartFeature 담당. 신선도는 사망 상태로 판단하고 이동은 SetMove로 통일.
- ActorService가 HitBox를 직접 읽어 중계 접근 제거. EAIState·AI*State로 이름 통일, .meta GUID 유지.
- 인터페이스 필요성을 직접 지적해 비제네릭 UnitController 기반으로 변경, IActor·IHitTarget·getter 중복 제거. 제네릭은 Def만 보유하고 필드명 유지로 재굽기 불필요.
- 직접 Unit 쪽이 아직 혼란스럽다고 지적해 AI에 문제점·개선안 정리를 맡김. 판단을 양쪽 다 Feature로(B)·공통 반응을 기반에서(C)·층별 폴더(A) 중 B·C만 진행 선택.
- AI가 BrainFeature(전투 종료 시 스스로 멈춤·피격·사망·행동 끝 훅) 도입, 플레이어 입력은 PlayerInputFeature로, 몬스터 대상·스폰 자리·행동 뒤 판단은 AIFeature로 옮김. 컨트롤러는 SetFeatures·CreateBrain만 남기고 OnUpdate·OnHit·OnDied·OnBattleEnded 폐지, HitParams.Attacker를 UnitController로 바꿔 TryGetComponent 제거.
- 직접 통합 후보 중 팀·사망 여부·콤보 다음 타·대상(TargetFeature)·애니 이름(AnimKey)·AttackChoice 위치를 채택, 대시 수치는 스킬 통합 때로 보류. AI가 반영하고 Unit/Core·Data·Feature·Action·Brain 층별 폴더로 이동(.meta 함께, PC 스크립트).
- 직접 "판단=Feature, 행동=Action"만으로는 정리가 안 된다고 지적. AI가 Feature를 상태·능력·입구로 나눈 역할표를 만들고, 얇은 Feature 합치기 후보(HitBox→Hit 등)를 제안.
- 직접 Feature 계층(능력·상태·입구·층) 혼재가 가장 산만하다고 지적. AI가 부품·행동·판단 3층과 호출 방향 고정을 제안, 직접 Health 분리 유지와 한 덩어리씩(부품 → 행동 → 판단) 진행·단계마다 컴파일·커밋을 선택.
- AI가 HitBox→Hit, ActionFeature→ActionLayer·Melee→AttackAction, BrainFeature→BrainLayer(Player/MonsterBrain)·Target→TargetSensor·AttackChoice→MonsterBrain 안으로 반영. 직접 프로퍼티 이름을 ActionLayer로 바꿔 판단도 BrainLayer로 맞춤.
- 위 구조 변경은 3단계 컴파일 안 함(1·2단계는 직접 컴파일·커밋).
- 직접 "AI 상태가 MonsterBrain만 받으면 의미가 없다"고 지적. AI가 AIBrain 기반으로 상태를 몬스터 판단에서 떼는 안을 제안, 직접 채택(3단계는 직접 컴파일 확인).
- AI가 심사자 관점 점검에서 "쓰이지 않는 일반화"를 짚고 IAIDef 제거·두 번째 판단 추가를 제안. 직접 채택해 버더지 BurrowBrain(맞으면 땅속에 숨는 AIHideState를 SetState로 추가, MonsterDef.Brain으로 선택) 반영(컴파일 전).
- 직접 보스 상태(포효·부위 파괴 쓰러짐·분노)와 동료 판단 추가, 숨은 적 조준 제외를 지시. AI가 무적 전체를 빼면 피격 직후 무적 때문에 콤보 조준이 튀어서 숨기 전용 플래그(HitF.IsHidden)로 좁힘.
- 직접 "상속으로 판단을 쪼개니 지저분하고 Idle·Dead가 몬스터 전용인 이유가 없다"고 지적. AI가 원인을 MonsterDef에 섞인 AI 수치로 짚고, 판단 하나(AIBrain)+상태 하나(AIState)+종류별 상태 묶음(AISpec.Type)과 드롭의 DropFeature 분리를 제안, 직접 채택. AI 수치는 공유 SO 대신 MonsterDef 안 직렬화 클래스(AISpec)로 옮김(자동 배정이 몬스터별 값을 쓰기 때문). 몬스터 에셋 15개 YAML 이전·데이터 툴 경로 수정(컴파일 전).
- 직접 "AI Def로 일반화해 프리셋 재활용"을 지시. AI가 AISpec을 공유 SO AIDef(프리셋 Normal·Burrow·Elite·Boss·Pet 5개)로 바꾸고 UnitDef.AI로 참조, 이동 속도만 UnitDef.MoveSpeed로 몬스터별 유지. 몬스터 15개 에셋 프리셋 배정, 자동 배정은 MoveSpeed만 기록(컴파일 전).

- 버섯 목록을 직접 요청대로 2/3 크기로(글자 27). 스킬 아이콘 스레드에서 다시 그린 밤 시계(흰 링·정각 눈금, 하늘 띠 48x240)를 연결: 원형 색 채움 대신 둥근 마스크 안에서 하늘 띠가 밤이 지난 만큼 1픽셀 단위로 내려감(UINightClock). 대장이 손본 HUD 프리팹은 시계 부분만 고침. 컴파일 통과, 플레이 확인 안 함.

## 전투 HUD 2단계: 체력바

- 직접 버섯 합계 줄 삭제, 배경 없는 라벨은 외곽선 폰트(대장이 만든 Galmuri11_OutLine SDF)로를 요청. AI가 HUD 프리팹을 다시 만들지 않고 해당 부분만 고침(연계·버섯 목록 라벨), 생성 코드에 UIBuilder.OutlineFont 추가.
- 2단계: UIGauge가 줄어들 때 안쪽이 잠깐 흔들리게(잔상은 기존). UIUnitHpBars를 만들어 잡몹·엘리트는 체력이 줄면 머리 위 작은 바를 3초(Define.MonsterHpBarShowTime), 보스는 어그로(TargetSelector.HasTarget)가 끌리면 화면 위 큰 바 + 이름, 분노(AIBrain.IsEnraged)면 "분노!" 표시. 분노 아이콘 그림은 아직 없어 글자로 둠. 컴파일 통과, 플레이 확인 안 함.

## 지도 배경 일러스트

- 직접 요청: 토벌 탭 지도 배경, 초원 → 얼음지대 → 원시림을 그라데이션 3분할로.
- AI가 256x144 위에서 본 도트 지도(UI_Map_Background)를 스크립트로 그림. 구불구불한 경계를 디더로 섞고, 초원(강·나무·꽃), 얼음(언 호수·눈 덮인 침엽수), 원시림(빽빽한 수관·야자·화산)을 넣음. MapDef.MapPosition 세 지점에 공터와 점선 길을 맞춤. 프리팹 연결은 안 함.
