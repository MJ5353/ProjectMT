# 정비 강화 노드 설계

최종 수정: 26.11.23

진행 상황은 Goals 저장소 `ProjectMT/작업 리스트.md`에서 관리한다.

## 1. 상세 정보

### 강화 노드

골드로 노드를 열어 능력치와 스페셜을 얻는다. 기본 노드 25개(5줄 × 5개), 연계 4개, 극의 5개로 총 34개이며, 아래 수치·비용은 가안이다.

| 능력치 줄 | 노드 1개당 효과 |
|---|---|
| 공격력 | 피해 배율 +10% |
| 공격 속도 | 공격 시간·애니 배속 +6% |
| 회피 | 대시 쿨 감소 +12% |
| 방어 | 받는 피해 감소 +6% |
| 최대 체력 | 최대치 +20% |

- 줄 노드는 앞 노드가 열려야, 연계는 지정한 이웃 두 줄의 노드가 모두 열려야, 극의는 해당 줄 끝까지 열려야 구매할 수 있다.
- 줄 노드 비용은 50·100·200·400·800G, 연계는 300 또는 600G, 극의는 1500G다. 조건 미달·골드 부족·이미 열린 노드는 구매할 수 없고, 구매 즉시 저장한다.

### 스페셜

| 노드 | 선행 조건 | 효과 |
|---|---|---|
| 버섯 사냥꾼 | 공격력 2 + 공격 속도 2 | 부위 피해 +25% |
| 질주 베기 | 공격 속도 3 + 회피 3 | 달리다 베기 공격력 +50% |
| 상해보험 | 회피 1 + 방어 1 | 맞으면 골드 동전 5~10개를 떨굼. 주워야 획득 |
| 든든한 뿌리 | 방어 3 + 최대 체력 3 | 체력 30% 이하에서 방어 보정 +30% |
| 바바리안 | 공격력 끝 | 콤보 막타 공격력 +50%·판정 반지름 +30% |
| 탁월한 속도 | 공격 속도 끝 | 이동 속도 +15% |
| 질풍 | 회피 끝 | 대시 거리 +30% |
| 강철 갓 | 방어 끝 | 경직 저항 +1 |
| 포자 재생 | 최대 체력 끝 | 버섯 한 개를 주울 때 체력 3 회복 |

같은 능력치의 보정은 합산한다. 대시 쿨 하한은 `PlayerDef.Dash.MinCooldownRate`(현재 기본 쿨의 20%), 방어 계산의 피해 배율 하한은 20%다.

### 엠블렘

연 노드 수로 단계가 오르고 도달한 단계들의 보너스를 누적 적용한다. 단계별 그림 5장을 사용한다.

| 단계 | 필요 노드 수 | 추가 보너스 |
|---|---|---|
| 새싹 채집꾼 | 0 | 없음 |
| 숲의 채집꾼 | 8 | 최대 체력 +5% |
| 밤의 사냥꾼 | 16 | 공격력 +5% |
| 포자 수호자 | 24 | 방어 보정 +5% |
| 버섯왕 | 34 | 기본 능력치 5종 보정 +5% |

### 데이터와 전투 적용

- `GearNodeDef`는 수정치·패시브·비용·선행 노드를, `EmblemDef`는 필요 노드 수·그림·수정치를 정의한다. `GearData`는 열린 노드 ID와 구매·엠블렘 조회를 맡고 세이브 v5의 `gearNodes`에 저장한다.
- **전투 적용은 SpawnService가 플레이어 스폰 때 수행한다.** 열린 노드·도달한 엠블렘을 `StatFeature`·`PassiveFeature`의 출처로 넣는다.
- 능력치는 `EStatType`·`StatModifier`로 통일한다. 기본 5종 외 이동·부위 피해·대시 거리·경직 저항·판정 범위(`AttackRadius`)를 지원하며 최종값은 `기본값 × (1 + Rate 합) + Add 합`이다.
- 패시브는 `언제 + 조건 + 효과`를 조합한다. 발동 시점은 공격·받는 피해·피격 후·줍기·퍼펙트 닷지이며, 조건·효과는 SerializeReference 드롭다운으로 구성한다.
- `DamageCalculator`가 공격·부위·방어와 순간 패시브 보정을 계산한다. 대시·러시 기본값은 `PlayerDef.Dash·Rush`에서 조절한다.
- 지역 난이도는 `MapDef.ListMonsterModifier`를 몬스터 스폰 때 적용한다. 얼음은 체력 +100%·공격 +50%, 공룡은 체력 +300%·공격 +125%이며 몬스터·스킬 에셋은 지역 배율을 뺀 기본값을 사용한다. 부위 내구도는 지역 배율에서 제외한다.

### 화면과 데이터 갱신

화면은 엠블렘·노드 트리·선택 노드의 효과/조건/비용과 강화 조작으로 구성한다. `ScreenLobby_GearView`와 생성기를 통해 잠김·구매 가능·열림 상태를 표시한다.

- 기본 데이터 생성: `MushTaker/초기 설정/정비 노드·엠블렘 만들기`. 수치·비용·그림은 `Resources/Data/Gear`, 패시브는 `Resources/Data/Passive` 에셋에서 수정한다.
- UI 반영: `UI 프리팹 표 갱신` 후 정비 화면을 선택해 다시 만든다. 골드 픽업은 데이터 편집기의 버섯 화면 `픽업 전체 빌드`로 생성한다.

## 2. 결정된 사안

- **26.11.22:** 정비는 골드 강화 노드·엠블렘으로 구성하고, % 강화가 정수 반올림으로 사라지지 않도록 피해·체력·내구도 수치 단위를 확대했다.
- 스페셜별 클래스를 늘리는 대신 공용 능력치 수정과 조건·효과 조합형 패시브를 채택했다.

## 3. 미정·후속 기획

- 강화 없이 평원, 중간 강화로 얼음, 충분히 강화한 뒤 공룡 지역을 공략하는 흐름이 밸런스 목표다. 노드·보너스·비용은 조정 대상이다.
- 무기·방어구 장착과 코스튬은 후속 범위이며 정비 탭에는 추가 예정 안내를 둔다. 입수 방식과 무기별 모션 변경 여부는 미정이다.
