# 정비 강화 노드 설계

최종 수정: 26.11.22

## 목표

정비 탭에서 골드로 강화 노드를 열어 능력치 5종을 올리고, 특정 노드에서 스페셜 능력을 얻는다. 연 노드 수에 따라 왼쪽 엠블렘이 단계별로 바뀌며 보너스를 준다. 무기·방어구 장착과 코스튬 변경은 추가 예정으로 명시만 한다.

## 1. 능력치 5종

| 능력치 | 노드 1개당(가안) | 끝까지(5노드) | 전투 반영 |
| --- | --- | --- | --- |
| 공격력 | 피해 +10% | +50% | 공격 판정 피해 배율 |
| 최대 체력 | +20% | +100%(50 → 100) | HealthFeature 최대치 |
| 회피 | 대시 쿨 -12% | -60%(0.5 → 0.2초) | DashAction 쿨 |
| 방어 | 받는 피해 -6% | -30% | HitFeature 피해 감소 |
| 공격 속도 | 공격 애니 +6% | +30% | AttackAction 시간·애니 배속 |

## 2. 노드 트리

- 5줄(공격력 · 공격 속도 · 회피 · 방어 · 최대 체력)을 나란히 두고, 줄마다 아래에서 위로 5노드. 앞 노드를 열어야 다음 노드가 열린다.
- 이웃한 두 줄 사이에 **연계 노드**가 있다. 두 줄의 지정 노드를 모두 열어야 열린다.
- 줄 끝 위에 **극의 노드**가 있다. 그 줄을 끝까지 열면 열린다.
- 노드는 능력치만, 스페셜만, 둘 다 가질 수 있다(데이터로 정함).

### 스페셜 능력(가안, 대장 지정 3개 + Claude 제안)

| 노드 | 조건 | 효과 |
| --- | --- | --- |
| 상해보험(대장) | 회피 1 + 방어 1 | 맞으면 골드 5~10 획득 |
| 탁월한 속도(대장) | 공격 속도 끝 | 이동 속도 한 단계(+15%) |
| 바바리안(대장) | 공격력 끝 | 막타 내려찍기 피해 ×1.5, 범위 +30% |
| 버섯 사냥꾼 | 공격력 2 + 공격 속도 2 | 부위(버섯) 피해 +25% |
| 질주 베기 | 공격 속도 3 + 회피 3 | 달리다 베기 피해 +50% |
| 든든한 뿌리 | 방어 3 + 최대 체력 3 | 체력 30% 이하일 때 받는 피해 -30% |
| 질풍 | 회피 끝 | 대시 거리 +30% |
| 강철 갓 | 방어 끝 | 약한 공격에 움찔하지 않음(경직 저항) |
| 포자 재생 | 최대 체력 끝 | 버섯을 주울 때 체력 3 회복 |

### 비용(가안)

- 줄 노드: 1~5번째 50 · 100 · 200 · 400 · 800 골드.
- 연계 노드: 300(1단) · 600(2단) · 900(3단), 극의 노드: 1500.
- 한 밤 수입을 아직 재보지 않아 숫자는 플레이 후 조정한다.

## 3. 엠블렘

- 왼쪽에 엠블렘 그림, 아래에 단계 이름·연 노드 수(n/34)·다음 단계까지 남은 수·지금 보너스.
- 단계(가안): 새싹 채집꾼(0) · 숲의 채집꾼(8) · 밤의 사냥꾼(16) · 포자 수호자(24) · 버섯왕(34).
- 단계 보너스(가안, 누적): 최대 체력 +5% → 공격력 +5% → 받는 피해 -5% → 5종 모두 +5%.
- 그림은 단계별 5장. 리소스 제작 전에는 색만 다른 임시 그림.

## 4. 장비·코스튬(예정)

- 정비 탭 아래쪽에 "무기·방어구 장착, 코스튬 변경 추가 예정" 안내를 둔다. 기획서 정비 항목에도 같은 내용 명시.

## 5. 밸런스 재편

- 피해·체력이 정수 1~5라 % 강화가 반올림으로 사라진다 → 모든 피해·체력·부위 내구도를 ×10.
  - 플레이어 체력 5 → 50, 공격 10·10·20(막타)·20(달리다)·10(회오리).
  - MonsterBalance BaseHp 3 → 30, BaseDamage 1 → 10. 몬스터 Def의 MaxHp·공격 피해·부위 내구도도 ×10.
- 지역 배율을 체력 1.8 → 2.0, 공격 1.4 → 1.5로 올렸다(몬스터 에셋도 같은 비율로 맞춤). 강화 없이 평원, 절반쯤에 얼음, 거의 다 열고 공룡을 깨는 흐름이 목표.

## 6. 데이터 구조

- 능력치: `EStatType`(Attack, MaxHp, Dodge, Defense, AttackSpeed, MoveSpeed, PartDamage, DashDistance, BreakResist)와 수정치 `StatModifier`(능력치, Rate/Add, 값). 정비 전용이 아니라 장비·코스튬·버프도 같은 수정치를 쓴다.
- `StatFeature`(유닛 부품): 출처별 수정치를 AddSource/RemoveSource로 받고, 최종값 = Def 기본값 × (1 + Rate 합) + Add 합. 바뀌면 Changed(최대 체력이 다시 계산). 풀에서 다시 꺼낼 때 비운다.
- `GearNodeDef`(DataDef): 수정치 목록, 패시브(PassiveDef, 없으면 비움), Cost, Requires, Slot. 에셋 `GearNode_NNN_Xxx`.
- `EmblemDef`(DataDef): 필요 노드 수, 그림(단계 색은 그림에 담음), 수정치 목록. 에셋 `Emblem_NNN`.
- `GearData`(PlayerDataBase): 연 노드 ID 집합, TryOpen → `GearChanged`. ApplyTo(플레이어)가 연 노드·엠블렘의 수정치는 StatFeature에, 패시브는 PassiveFeature에 출처로 넣는다. 세이브 v5 `gearNodes`.
- 피해 계산은 `DamageCalculator` 한곳(때린 쪽 공격력 + 패시브 ModifyAttack → 부위 → 맞는 쪽 방어 + 패시브 ModifyTaken).
- 표시 글은 `StatModifier.ToText()`가 `Stat_` + 능력치 이름 문구 키를 쓴다. 능력치를 추가하면 EStringKey에 한 줄만 더한다.
- 스페셜은 `PassiveDef`(DataDef) 에셋 `Passive_NNN_Xxx`(Resources/Data/Passive). 훅 4곳: ModifyAttack(피해·범위), ModifyTaken(받는 피해), OnHit(맞은 뒤), OnPickup(주운 뒤). 종류: SkillBoost(질주 베기·바바리안), LowHpGuard(든든한 뿌리), GoldOnHit(상해보험, 골드 동전 픽업 `Pickup_Gold`를 떨굼), HealOnPickup(포자 재생). `PassiveFeature`(유닛 부품)가 출처별로 모아 훅을 돌린다.
- 지역 난이도: `MapDef.ListMonsterModifier`를 몬스터 스폰 때 StatFeature 출처로 넣는다(얼음 체력 +100%·공격 +50%, 공룡 체력 +300%·공격 +125%). 몬스터·스킬 에셋은 지역 배율을 뺀 기본값. 부위 내구도는 지역 배율 없음.

## 7. UI

- `ScreenLobby_GearView`(UITabView), LobbyUISetup이 생성.
  - 왼쪽: 엠블렘 그림·단계·진행도·보너스.
  - 가운데: 노드 트리(5줄 + 연계·극의 노드, 연결선). 노드 상태 잠김 · 열 수 있음 · 열림.
  - 오른쪽: 고른 노드 이름·효과·조건·비용·[강화] 버튼(골드 부족·조건 미달이면 꺼짐).
  - 아래: 장비·코스튬 추가 예정 안내.
- 노드 칸 `ScreenLobby_GearView_Node`. 문구는 StringDef `Lobby_Gear_` 키.

## 8. 적용 순서(Unity)

1. 컴파일 후 메뉴 `MushTaker/초기 설정/정비 노드·엠블렘 만들기` → Resources/Data/Gear에 34노드·5엠블렘 생성, DB 갱신.
2. `UI 프리팹 표 갱신`(Lobby_Gear_ 문구 채움) → `모든 UI 다시 만들기`(ScreenLobby 정비 탭).
3. 노드 값·비용은 GearNode_* 에셋에서, 엠블렘은 Emblem_* 에셋에서 고친다. 엠블렘 그림은 Icon_Emblem_001~005.
4. 메뉴 `픽업 전체 빌드`로 `Pickup_Gold`(골드 동전)·`M_Gold`를 만든다.
