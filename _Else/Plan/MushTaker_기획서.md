# MushTaker 기획서

최종 수정: 26.11.23 · 원본 Doc: https://claude.ai/artifact/PKJGtp2g5wa5HDJWdonvTn

진행 상황은 Goals 저장소 `ProjectMT/작업 리스트.md`에서 관리한다.

## 1. 상세 정보

### 개요와 한 판의 흐름

버섯 난 괴물을 부위 파괴 액션으로 사냥하고 남은 밤에 현장 시장에서 파는 3D 복셀 액션 게임이다. 이 숲의 버섯은 해가 뜨면 썩으므로 사냥량과 판매에 남길 시간을 함께 판단한다.

1. 정비에서 골드로 강화 노드를 열고 토벌 지도에서 지역을 고른다.
2. 맵 진입 후 ‘클릭하여 시작’을 누르면 전투와 밤 카운트다운이 시작된다.
3. 몬스터를 사냥하고 보스 부위를 깨 버섯을 모은다. **토벌 종료** 확인 후 주운 버섯과 남은 밤을 받아 시장을 연다.
4. 시장에서는 거래·기다리기 때만 시간이 줄어든다. 판매를 마치거나 시간이 끝나면 보상을 정산하고 결과 화면에서 다시 하기·로비 이동을 고른다.

밤 길이는 지역의 `MapDef.NightTime`으로 정하며 수치는 가안이다. 사냥을 오래 할수록 수확은 늘지만 판매 행동에 쓸 시간이 줄어든다.

### 전투와 버섯

- 이동, 연타 콤보, 위로 치기, 달리다 베기, 길게 누르기 회오리, 무적 대시를 사용한다. 가까운 적을 자동 조준하며 서는 자리·공격 높이로 부위를 노린다.
- 공격 예고를 읽고 피한 뒤 빈틈에 공격한다. 공격 직전 범위에 있다가 대시로 피하면 퍼펙트 닷지 후 슬로우·대상 접근·연타·막타의 반격 러시로 이어진다.
- 현재 부위 파괴는 보스를 대상으로 하며 부위별 내구도·본체 피해 배율을 설정한다. 내구도가 소진되면 버섯을 떨구고 보스가 다운하며, 재생 시간이 있는 부위는 다시 자란다.
- 체력이 줄어 분노하면 포효 후 공격 쿨과 분노 전용 스킬 후보가 달라진다. 경직 저항과 부위 파괴 다운은 구분한다.
- **희귀도**는 드롭 때 지역 가중치로 결정한다. **신선도**는 살아 있는 괴물의 부위 파괴가 상급, 사망 드롭이 하급이며 시장 가격에 각각 반영한다.

### 지역과 해금

평원·얼음·공룡 3지역에 잡몹 무리·엘리트·보스를 배치한다. 기본 지형과 프랍·종류·난이도·드롭 가중치는 지역 데이터로 구성한다.

- **기획 기준:** 해당 지역 보스를 처음 잡으면 다음 지역이 열린다.
- **현재 구현 차이:** 보스 처치 여부와 관계없이 시장을 거쳐 종료한 결과를 클리어로 기록한다(`BattleService.Finish`의 `EHuntResult.Exited`). 보스 첫 처치 원안과 구분해 둔다.

### 쓰러짐과 토벌 종료

| 상황 | 현재 동작 |
|---|---|
| 쓰러짐 | 들고 있던 버섯을 전부 바닥에 떨구고 밤 시계를 멈춤. 골드로 같은 자리에서 부활해 다시 줍거나 버섯을 포기하고 귀가 |
| 전투 중 밤 소진 | 시장을 거치지 않고 주운 버섯을 썩은 버섯으로 정산 |
| 시장 종료 | 판매 골드·신뢰도를 반영하고 남은 버섯을 썩은 버섯으로 전환 |

전투 중 주운 골드 동전은 즉시 인벤토리에 반영되어 쓰러짐·귀가에도 유지된다. 부활 비용·무적 시간·사망 팝업 지연은 `DefineDef.Battle`에서 조절한다.

### 로비와 성장

하단 탭은 **정비·토벌·개량·파견** 순서이며 토벌이 기본이다. 현재 플레이 루프는 정비 → 토벌 → 현장 시장 → 정비로 이어지고, 개량·파견은 준비 중으로 표시한다.

| 탭 | 내용 |
|---|---|
| 정비 | 골드로 5종 능력치의 강화 노드·연계/극의 스페셜을 열고 엠블렘 보너스 획득 |
| 토벌 | 지역 선택·해금 상태·나오는 버섯을 확인하고 입장 |
| 개량 | 후속 기획: 썩은 버섯 2종을 배양해 변종 획득, 조합 도감·수집가 판매·키메라 재료로 사용 |
| 파견 | 후속 기획: 버섯 4개로 키메라를 만들어 깬 지역에서 자동 사냥, 새벽 보상 수령. 재료 신선도에 따라 수명 변화 |

### 후속 기획과 콘텐츠

- 무기·방어구 장착과 코스튬 변경은 정비 확장 범위다. 버섯으로 장비를 제작하지 않는다.
- 머리·다리별 반응 차이, 깨진 부위를 쓰는 공격의 약화, 말불버섯 팽창·포자 피해는 전투 확장 아이디어로 남긴다. 현재 부위 파괴·다운 동작과 구분한다.
- 키메라 조합 가안은 송이 4개=버끼, 구름 3+송이 1=버곰, 말불 2+송이 2=종류 미정이다. 키메라는 직접 조작하지 않는다.
- 콘텐츠는 ScriptableObject 데이터와 모델·애니·아이콘을 연결해 추가한다. 시장·성장 수치와 상세 규칙은 [시장 기획서](시장_기획서.md)·[정비 설계](정비_강화노드_설계.md)에 둔다.
