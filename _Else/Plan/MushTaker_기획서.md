# MushTaker 기획서

최종 수정: 26.11.17 · 원본 Doc: https://claude.ai/artifact/PKJGtp2g5wa5HDJWdonvTn

## 개요

복셀 숲에서 버섯 몹을 툭툭 쳐서 잡고, 떨어진 버섯으로 재배하고 키메라를 만들어 다시 사냥하는 모바일식 액션 게임이다.

- **한 판:** 3~5분. 사냥 한 번이 곧 한 판이다.
- **핵심 재미:** 단순한 타격 손맛, 그리고 어떤 버섯을 모아 무엇을 만들지 고르는 재미.
- **그래픽:** 3D 복셀(도트) 스타일, 3인칭 카메라.
- **화면 구분:** 인게임은 사냥 필드, 아웃게임은 하단 탭 4개(사냥·재배·제작·편성).

지켜야 할 조건은 아래 8가지다.

1. 버섯의 성질이 들어갈 것
2. 에셋을 마련하거나 만들 방법이 있을 것
3. 조작이 단순할 것
4. 다른 게임과 너무 비슷하지 않을 것
5. 사이클이 확장 가능하고 모바일스러울 것
6. 3~5분 분량의 플레이
7. 도트 그래픽(2D, 3D 모두 가능)
8. 여러 버섯을 활용할 것

## 인게임: 사냥 필드

복셀 풀밭 한 판에 버섯 몹 몇 마리가 돌아다니고, 플레이어는 키메라를 조작해 툭툭 쳐서 잡는다.

### 화면과 조작

- 넓지 않은 복셀 필드 한 장, 3인칭 쿌터뷰 카메라.
- 조작은 3개다. 조이스틱(이동), 공격 버튼, 교대 버튼(편성한 키메라 3마리 중 다음 마리로).
- PC 시제품에서는 WASD·마우스 클릭·탭 키로 같은 조작을 한다.

### 타격 손맛

- 맞으면 넉백, 몸이 하얗게 번적, 짧은 멈춤(히트스톱), 복셀 조각이 튀는 이펙트.
- 몹은 맞으면 반격하고, 공격 전에 잠깐 움츠리는 예비 동작이 있다. 예비 동작을 보고 빠지면 된다.

### 버섯 몹 (버섯 성질이 들어가는 곳)

| 몹 | 버섯 성질 | 전투에서 | 드랍 |
| --- | --- | --- | --- |
| 버끼 | 송이, 작고 흔함 | 무리로 다니고 맞으면 도망감 | 송이버섯 |
| 버곰 | 단단한 나무 갓 | 느리고 세게 내리침. 갓을 먼저 깨야 몸에 피해 | 구름버섯 |
| 버우르스(보스) | 말불버섯, 포자 폭발 | 맞을수록 부풀고, 터지면 포자 구름 | 말불버섯 |

- 버곰의 갓처럼 몸에 난 버섯을 깨면 그 버섯이 더 떨어진다. 부위 파괴와 비슷한 목표를 여기서 준다.
- 몹 이름과 생김새는 확정 전이다.

### 한 판 흐름

1. 사냥 탭에서 숲을 고르고 출발
2. 필드에서 버끼·버곰을 잡으며 버섯 줍기
3. 일정 수를 잡으면 버우르스 등장
4. 버우르스를 잡으면 승리, 키메라 3마리가 다 쓰러지면 패배
5. 결과 화면에서 주운 버섯을 가지고 아웃게임으로

## 아웃게임: 하단 탭 4개

사냥에서 얻은 버섯이 재배와 제작을 거쳐 더 강한 편성이 되고, 그 편성으로 더 깊은 숲을 사냥한다.

루프: 사냥(버섯 드랍) → 재배(버섯 늘리기) → 제작(키메라 4개 조합) → 편성(3마리 강화해 출발) → 사냥

| 탭 | 하는 일 | 모바일식 요소 |
| --- | --- | --- |
| 사냥 | 숲 고르고 출발(인게임 진입). 숲 하나를 깨면 다음 숲이 열린다 | 스테이지 진행 |
| 재배 | 주운 버섯을 밭에 심고, 다 자라면 뽑는다. 하나를 심으면 여러 개가 나온다 | 실시간 타이머, 들렀다 가는 탭 |
| 제작 | 버섯 4개를 냄비에 넣으면 레시피대로 키메라가 나온다. 송이 4개면 버끼. 모르는 조합은 ???로 남고 찾으면 도감에 오른다 | 수집, 도감 |
| 편성 | 버섯을 먹여 키메라를 강화하고, 사냥에 데려갈 3마리를 고른다 | 육성, 덱 편성 |

### 제작 레시피 예시

| 재료 4개 | 키메라 | 특징 |
| --- | --- | --- |
| 송이 4 | 버끼 | 빠른 근접 공격 |
| 구름 3 + 송이 1 | 버곰 | 느리고 세게 내리침, 단단한 갓에 강함 |
| 말불 2 + 송이 2 | 이름 미정 | 포자 구름 폭발(범위 공격) |

- 레시피에 없는 조합은 약한 키메라나 실패작이 나온다. 상세 규칙은 미정이다.
- 키메라 이름은 몹과 같아도 되는지 확인이 필요하다. 잡은 몹을 내 편으로 다시 만드는 구조로 보면 자연스럽다.

## 데이터와 콘텐츠 추가

콘텐츠는 모두 데이터 표(ScriptableObject 또는 CSV) 한 줄로 늘린다. 코드를 고치지 않고 새 버섯·몹·레시피를 넣는 것이 목표다.

| 표 | 주요 값 | 새로 넣을 때 필요한 에셋 |
| --- | --- | --- |
| 버섯 | 이름, 재배 시간, 수확량, 강화치 | 복셀 버섯 모델 1개, 아이콘 |
| 몹 | 체력, 공격 패턴, 드랍 표, 버섯 부위 | 복셀 몹 모델과 애니 |
| 레시피 | 재료 4개, 결과 키메라 | 없음 |
| 키메라 | 공격 종류, 스탯, 강화 재료 | 몹 모델 재사용 가능 |
| 숲 | 등장 몹, 보스, 해금 조건 | 바닥 블록 색만 바꿔도 됨 |

몹 패턴은 BT/FSM, 타격과 버섯 부위는 조합형 피격 구조, 재배·강화 표는 방치형 라이브 경험을 그대로 쓴다.

## 11/19까지 범위와 순서

인게임 손맛을 먼저 만들고, 아웃게임은 탭마다 기능 하나씩만 붙여 한 바퀴를 돌린다.

1. **인게임 시제품:** 복셀 필드, 이동·공격, 버끼 1종, 넉백·번쩍·드랍·줍기
2. **몹 추가:** 버곰(갓 파괴), 버우르스 보스, 승패와 결과 화면
3. **아웃게임 탭:** 사냥(숲 1개) → 재배(심고 뽑기) → 제작(레시피 3개) → 편성(3마리 고르기, 강화 1단계)
4. **다듬기:** 숲 하나 더, 사운드, 모바일 조작 UI

### 미정 사항

- [ ] 플레이어가 키메라를 직접 조작하는지, 채집꾼 한 명이 키메라를 데리고 다니는지
- [ ] 몹과 키메라의 이름·생김새 (에셋 스레드와 함께)
- [ ] 레시피에 없는 조합의 결과
- [ ] 재배 타이머 길이(시연용이면 수십 초)
