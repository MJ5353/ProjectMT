# 전투: 부위 파괴

최종 수정: 26.11.23

진행 상황은 Goals 저장소 `ProjectMT/작업 리스트.md`에서 관리한다.

## 1. 상세 정보

### 플레이 규칙

보스의 버섯 난 부위를 노려 깨고 수확한다. 공격 높이·자리·보스의 자세에 따라 닿는 부위가 달라지며, 다운은 높은 부위를 노릴 기회가 된다.

- **부위:** 몸 부위별로 내구도를 따로 관리한다. 한 부위에는 여러 소켓과 버섯이 속할 수 있으며, 스폰 때 데이터의 개수 범위와 사용 가능한 소켓 안에서 배치한다.
- **피해:** 몸을 맞히면 본체 체력만 줄고, 파괴 가능한 부위를 맞히면 내구도와 본체 체력이 함께 줄어든다. 본체 피해에는 부위별 배율을 적용하며, 이미 깨졌거나 자라는 중인 부위는 몸 피격으로 처리한다.
- **파괴:** 내구도가 0이 되면 꽂힌 버섯마다 확정 드롭하고 깨진 모델로 바꾼다. 깨진 모델이 없으면 숨긴다. 내구도 0으로 설정한 부위는 깨지지 않는 장식이다.
- **다운:** 현재는 부위가 깨지면 보스 감시가 다운을 예약한다. 공격·피격·대시·예약 콤보가 없을 때 `DownCore`가 `PartBreak → Down`을 재생하며, 다운 시간은 `AIDef.DownTime`으로 정한다.
- **재생:** `RegenTime > 0`인 부위만 대기 후 다시 자란다. 성장 시간이 끝나면 다시 깰 수 있고, 0이면 재생하지 않는다.
- **신선도:** 살아 있는 괴물의 부위 파괴는 상급, 사망 드롭은 하급이다. 다운은 사망과 구분하며 신선도를 낮추지 않는다. 희귀도는 드롭마다 지역 가중치로 별도 결정한다.

### 데이터와 구현 책임

| 구성 | 맡는 일 |
|---|---|
| `MonsterDef.PartEntry`·`ListPart` | 연결할 몸 부위, 버섯 모델·종류·개수·크기, 내구도·본체 피해 배율·재생 시간 |
| `UnitProperty.BonePart` | 프리팹의 `Hitbox_*` 뼈와 해당 부위의 `Socket_*` 참조. 프리팹 빌더가 연결 |
| `PartFeature` | 유닛당 하나로 모든 부위의 배치·내구도·깨짐·재생·드롭 관리 |
| `HitFeature`·`HitDef` | 부위·본체 피해, 경직 판단과 넉백·번쩍·히트스톱·조각·카메라 반응 |
| `HitShapeDef`·`HitShape` | 뼈 Y축을 따르는 구·캡슐 판정. `PartIndex`가 -1이면 몸, 0 이상이면 `ListPart`의 부위 |
| `UnitDef.ListSkill`·`SkillDef` | 기본 공격·스킬과 판정 뼈·구간·이동·연계 데이터 |
| `StateFeature`·`BossWatchSub` | 행동 전환과 부위 파괴 후 다운 예약 |

판정은 부위를 먼저 찾고 몸 판정을 확인하며, 모양이 없는 유닛은 CharacterController를 사용한다. 공격 한 번의 판정 구간에서는 같은 대상을 중복 타격하지 않는다.

상태 조립·공격 선택·분노 구조는 [유닛 구조 설계](../DevDocs/Unit_구조설계.md), 전투 흐름과 서비스 소유권은 [Flow 구조 설계](../DevDocs/Flow_구조설계.md)를 따른다.

## 2. 결정된 사안

- **26.11.18:** 최초 적용 대상은 기존 보스 나무로 정하고 모델·스폰 구조를 재사용하기로 했다.
- **26.11.18:** 반응마다 Feature가 늘어나는 것을 피하려고 피격 반응을 `HitFeature`와 공용 `HitDef`로 모으고, 체력은 별도 `HealthFeature`로 유지하기로 했다.

## 3. 미정·구현 차이

- **다운 조건:** 원안은 부위 N개 파괴 후 다운이다. 현재는 부위 파괴마다 다운을 예약하며, 누적 개수 설정과 필요 파괴 수는 반영되어 있지 않다.
- **사체 수확:** 원안은 사망 후 남은 부위를 뜯어 하급 버섯을 얻는 방식이다. 현재는 사망한 유닛의 피격을 받지 않고 사망 드롭을 하급으로 처리한다.
