# UI 리소스 제작 계획

## 1. 다음 단위 작업

체크리스트의 첫 미완료 제작 묶음인 **토벌 탭 지도 배경·지역 노드·자물쇠 아이콘**을 준비한다. 목록의 체크 상태는 작성 당시 기록이므로 현재 에셋을 대조한 뒤 착수한다.

## 2. 전체 작업 TODO 및 진행상황

`[x]`는 원본에서 완료 표시, `[ ]`는 미완료 표시다. 결함·개선 제안도 당시 기록으로 보존하며 현재 재현 여부는 확인하지 않았다.

### 필수 (14장)

- [x] 패널 틀: 9-slice 16×16. 창, 정보 패널, 상단 바, 탭 바에 씁니다.
- [x] 버튼: 9-slice 16×16, 보통과 눌림 2장.
- [x] 아이템 칸 배경: 9-slice 16×16.
- [x] 게이지: 틀과 채움 2장, 9-slice.
- [x] 버섯 아이콘 3장(송이, 구름버섯, 말불버섯): 24×24. 버섯 데이터의 Icon 칸에 넣습니다.
- [x] 골드 아이콘: 16×16.
- [x] 하단 탭 아이콘 4장(야시장, 토벌, 개량, 파견): 24×24.

### 토벌 탭 (3장)

- [ ] 지도 배경: 약 280×200(4배로 1100×800).
- [x] 지역 노드: 24×24. 색으로 상태를 구분합니다.
- [x] 자물쇠 아이콘: 잠긴 지역에 올립니다.

### 전투 HUD, 5단계 (6장)

- [x] 조이스틱 바닥 원과 손잡이 2장.
- [x] 공격, 대시 버튼 아이콘 2장.
- [ ] 보스 얼굴 아이콘: 보스 체력 바 옆에 둡니다.
- [x] 버섯 부위 상태 아이콘: 깨짐 1장. 정상과 재생 중은 버섯 아이콘을 다시 씁니다.

### 시장

- [ ] 상인 전신 초상 4장(약재상, 요리사, 수집가, 떠돌이 상인): 64×80. 화면 가운데에 크게 들어가요.
- [ ] 상인 얼굴 아이콘 4장: 24×24. 왼쪽 상인 목록에 씁니다. 초상에서 잘라도 돼요.
- [x] 경쟁·담합 아이콘 2장: 16×16. 갈무리 폰트에 ⚔, 🔗 글자가 없을 수 있어서 그림으로 두는 게 안전해요.
- [ ] 신선 등급 뱃지 3장(상급, 중급, 보통): 12×8. 인벤이 종류×등급 칸이라 이제 꼭 필요해요.
- [x] 말풍선: 9-slice 16×16, 꼬리 포함. 상인 반응 대사에 씁니다.
- [ ] 태그 칩: 9-slice 12×12. 상인 특징 태그("상급 선호" 등)를 감싸요.
- [x] 시각 아이콘 2장(달, 해): 16×16. 상단에서 지금 시각부터 새벽까지 남은 시간을 게이지로 보여 줄 때 양 끝에 둡니다.
- [x] 기다리기 아이콘(모래시계): 16×16. [30분 기다리기] 버튼에 넣어요.
- [ ] 시장 배경 1장: 480×270(4배로 1920×1080). 밤 숲속 노점 분위기예요.

### 버섯 아이콘

- [x] 나머지 버섯 아이콘 5장(노루궁뎅이, 표고, 팽이, 광대, 서리): 24×24. 시장 인벤에 8종이 다 나올 수 있어요.
- [x] 썩은 버섯 덮개 1장: 24×24. 곰팡이 얼룩을 아이콘 위에 겹쳐서, 종류별로 따로 그리지 않아도 됩니다.
- [x] 변종 표시: 8×8 별. 수집가가 노리는 변종 칸에 붙여요.

### 있으면 좋음

- [ ] 상인 표정 2장씩(기쁨, 불만), 모두 8장: 거래 반응용
- [ ] 판매 때 동전이 튀는 효과 프레임 3~4장


## 3. 상세 정보

리소스 크기와 사용 위치는 각 체크 항목에 적혀 있다. 패널·버튼·슬롯·게이지는 9-slice, 버섯·탭 아이콘은 주로 24×24 규격이다. 전투 HUD와 시장 화면의 해상도·용도도 위 목록을 따른다.

## 4. 결정된 사안

썩은 버섯은 종류마다 별도 그림을 만들지 않고 공통 덮개를 아이콘 위에 겹친다. 변종은 작은 별 표시를 붙인다. `[ ]` 항목은 확정된 제작 완료로 취급하지 않는다.
