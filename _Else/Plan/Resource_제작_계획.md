손봐야 할 것 (결함)

- [ ] 전투가 끝나도 계속 싸움
    승패가 난 뒤에도 몹이 공격하고 플레이어도 움직입니다. 결과 화면 버튼을 클릭하면 공격 입력으로도 들어갑니다. 끝나면 유닛 입력과 AI를 멈추는 게 좋습니다.
- [ ] 처치 수와 리스폰 집계가 불안함
    MobKilled에 어떤 몹인지가 안 실려서, 죽은 몹을 사전에서 찾아 그룹 수를 줄입니다. 같은 프레임에 둘이 죽으면 어긋날 수 있습니다. 이벤트에 몹을 싣거나 몹이 자기 그룹을 들고 있게 바꾸면 됩니다.
- [ ] 빌드에서 번쩍·조각이 안 보일 수 있음
    Shader.Find("URP/Unlit")으로 머티리얼을 만들어서, 빌드에서 셰이더가 빠지면 깨집니다. 머티리얼 에셋을 하나 만들어 프리팹에 연결하면 됩니다.
- [ ] 패배해도 주운 버섯을 다 받음
    지금은 [mj] todo로 남겨 둔 상태입니다. 규칙을 정해 주셔야 합니다.
