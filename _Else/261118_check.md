# 코드 점검 순서

최종 수정: 26.11.18

대상: 26.11.18 작업분(`0addc49` 이후 커밋 + 미커밋 3개)과 261117_check.md의 미확인 항목. 점검 순서는 어제와 같이 **기반 → Core → Data·Save → 전투 뼈대 → 유닛·Feature → 플레이어·몬스터 → UI → 에디터 도구**를 따른다.

## 1. 다음 단위 작업

미커밋 2개(`ChunkBurstService.Mark`, `HitFeature.ApplyChunkBurst`)를 먼저 보고 커밋 여부를 정한 뒤, 2단계 4번(부위 파괴)부터 점검한다.

## 2. 오늘 주요 변경점

- **미커밋**: 부위를 맞으면 타격 마크가 커지고(0.14) 오래 남으며(0.35초) 빨간 빛살 12칸이 더해진다. 판정은 `partIndex >= 0`이고 수치는 임시값이다.
- **구조 이름 변경**: Manager/Management → Service(`ActorService`, `BattleService`, `HitStopService`, `ChunkBurstService`, `PopupService`), `SEventService` → `SEventManager`, `RegionDef` → `MapDef`. `FlowService`·`BattleFlow`·`BattleManager`는 삭제되고 `GameManager`·`BattleService`·`RootManager`로 옮겨졌다.
- **Feature 정리**: `FlashFeature`·`KnockbackFeature`·`HitStopFeature`·`ChunkBurstFeature`가 삭제되고 `HitFeature`(+`HitDef`의 `EHitReaction`)로 합쳐졌다.
- **폴더 정리**: Data·Prefabs가 `Assets/Resources` 아래로 이동했다. 로드 경로 문자열이 모두 따라왔는지는 확실하지 않다.
- **명명 규칙**: 몬스터·맵 ID 규칙 변경(`Mon_005_Boss_Tree`, `Map_001_Field` 등), 애니 클립 이름은 `AnimNameMigration`으로 정리. 지시받은 `NamingMigration` 파일은 저장소에 없다(확실하지 않음, 이름이 다를 수 있음).
- **데이터 툴**: `DataEditorWindow`(730줄), `DataEditorChecks`, `DataEditorUtility`, `MonsterAutoFill`, `SkillDefAutoFill`, `BodyShapeAutoFill`, `MapSpawnAutoFill`, `MonsterBalanceTable`, `SerializableDictionary`+Drawer/Checks.
- **부위 파괴**: `PartFeature` 신규, `EBattlePartType`·`EMushroomPartType` 분리, `MushroomSocket.BattlePart`로 전투 부위와 연결. `HitRadius`는 코드에서 사라졌고 판정은 `HitShapeDef`(BodyShape) 기준이다.
- **보스 3종 공격**: `MonsterDef`·`SkillDef`·`MonsterAttackState`/`WindupState`로 연결. 몬스터 상태가 `MonsterStates.cs` 한 파일에서 `State/` 폴더 8개로 쪼개졌다.
- **플레이어**: 좌→우→막타 콤보, 달리다 베기, 길게 누르기(0.35초) 회오리, 공격 전환 0.08초 블렌딩. 회오리 재타격은 `AttackSpec.RehitFrame`으로 처리한다.
- **복셀 FBX 재출력**: `Player.fbx`, 보스 3종(`Mon_005/010/015`), 맵 3종(`Map_001~003`, SpawnSlot 포함). 옛 이름 FBX(`Boss_Tree`, `Map_Field01` 등)는 삭제됐다.
