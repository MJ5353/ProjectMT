# 콘텐츠 명명 규칙

최종 수정: 26.11.18
적용: 몬스터·버섯·맵 콘텐츠 또는 관련 에셋·ID를 추가하거나 이름을 변경할 때만 참고한다. (26.11.18 확정)

모든 콘텐츠의 기준 키는 **`NNN_Key`** (3자리 번호 + 이름)이며, 에셋 유형에 따라 접두사만 바꾼다. 모든 숫자는 3자리이다.

| 종류 | 형식 | 예 |
|---|---|---|
| 몬스터 모델 | `Mon_NNN_Key` | `Mon_001_Rabbit`, `Mon_005_Boss_Tree` |
| 몬스터 Def·ID·프리팹 | `Monster_NNN_Key` | `Monster_001_Rabbit` |
| 몬스터 스킬 Def·ID | 스킬 `Monster_NNN_Skill_NN`, 기본 공격 `Monster_NNN_Attack_NN` (번호는 순서 의미 없음, SkillDef.Kind로 구분) | `Monster_005_Skill_01`, `Monster_005_Attack_01` |
| 애니 클립·상태 | 기본 공격 `Attack_NN`, 스킬 `Skill_NN` (클립 이름 = 상태 이름). 이동·반응은 기존 이름 유지. 26.11.18 결정, 실제 이름 변경·데이터 이전은 보류 | `Attack_01`, `Skill_02` |
| 애니메이터 | `AC_NNN_Key` (플레이어는 `AC_Player`) | `AC_001_Rabbit` |
| 버섯 모델 | `Mush_NNN_Key` (깨진 버전 `_Broken`) | `Mush_001_Songi` |
| 버섯 Def·ID | `Mushroom_NNN_Key` | `Mushroom_002_Gureum` |
| 버섯 픽업·아이콘 | `Pickup_NNN_Key`, `Icon_NNN_Key` | `Pickup_001_Songi` |
| 머티리얼 | `M_Xxx` (`M_`은 머티리얼 전용) | `M_Voxel` |
| 지역 Def·맵 모델 | `Map_NNN_Key` (둘이 같은 이름) | `Map_001_Field` |
| 맵 스폰 지점 | `SpawnSlot_NNN` | `SpawnSlot_001` |

## 몬스터 · 지역

- 몬스터 키는 종족의 영어 이름(`Rabbit`, `Raptor`)으로 정하고, 도감 표시 이름에는 ‘버’를 넣는다(예: 버끼, 버랩터).
- 보스 키에는 `Boss_`를 포함한다.
- 몬스터 번호는 지역 순서대로 **잡몹 → 엘리트 → 보스**: 평원 `001~005`, 얼음 `006~010`, 공룡 `011~015`.
- 지역 번호: `001_Field`, `002_Ice`, `003_Dino`.

## 버섯

- 키는 한글 이름의 로마자 표기를 쓴다(`Cloud`가 아니라 `Gureum`).
- 버섯 Def의 `DexNo`는 이름의 `NNN`과 일치시킨다.
- 번호·키: `001_Songi`, `002_Gureum`, `003_Malbul`, `004_Noru`, `005_Pyogo`, `006_Paengi`, `007_Gwangdae`, `008_Seori`.

## 복셀 내보내기

- `tools/voxel/voxlib.py`의 `EXPORT_NAMES` 표를 기준으로 내보낸다.
- 새 몬스터·버섯을 추가하면 `EXPORT_NAMES`에도 반영한다.
