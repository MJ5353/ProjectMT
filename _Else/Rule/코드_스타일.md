# C# 코드 스타일

최종 수정: 26.11.18
적용: C# 파일을 작성·수정·리뷰할 때만 참고한다.
기준: `portfolio_mjKim/_Unity_Reference`의 ProjectR 코드 (26.11.17 정리).

## 선언·명명

- 네임스페이스 없이 전역 클래스를 사용한다.
- 필드 `m_PascalCase`, static `s_PascalCase`, 상수 `PascalCase`; 컬렉션 `m_DicXxx`·`m_ListXxx`.
- 접근 제한자를 항상 쓰고, 직렬화 필드는 `[SerializeField] private T m_Xxx = null;` 형식으로 둔다.
- `Def`의 단순 저장 값은 `[field: SerializeField] public T Xxx { get; private set; }` 형식으로 선언한다. 기존 필드 이동 시 `[field: FormerlySerializedAs("m_Xxx")]`로 직렬화 데이터를 보존한다.
- 지역·`out` 변수에 타입을 명시한다. `var`는 `foreach (var pair ...)` 정도만 허용한다.
- 열거형은 `E` 접두사, 매개변수 묶음은 `readonly struct XxxParams`, ID는 `ID`로 대문자 표기한다.
- 접미사: 전역 싱글턴 `XxxManager`, 하위 시스템 `XxxManagement`, 액터 부품 `XxxFeature`, 모음 `XxxHub`. 지역 약칭: `gameM`, `skillM`.

## 제어 흐름·수명 주기

- bool 부정은 `x == false`. 가드 구문으로 먼저 `return`한다.
- 한 줄 `if`는 중괄호 없이 다음 줄에 문장 하나를 둔다. `for`·`foreach`는 본문이 한 문장이어도 `{}`로 감싼다.
- 수명 주기는 `Init` / `Reset` / `Clear`, 갱신은 `Update(float deltaTime)`을 사용한다.

## 배치·주석

- Unity 이벤트 함수(`Awake`, `Start` 등)를 먼저 배치한다.
- 필드·프로퍼티와 메서드 사이의 경계 앞뒤에는 빈 줄과 `// ------------------------------------------------`를 둔다.
- 파일 최상위 타입 경계는 `// ==================================================`로 구분한다.
- 이름 있는 묶음은 `// 제목 ---`, 가상 함수 묶음은 `// virtual ---`로 표시한다.
- 주석은 짧은 한글로 쓴다. 경고 `// !!)`, 대장 메모 `// [mj] todo)`.
